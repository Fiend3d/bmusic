# bmusic

I use this tool for downloading music for my YouTube channel https://www.youtube.com/@buradoplays

# How to use

1. pip install -r requirements.txt
2. add the bmusic directory to your system PATH
3. download https://www.ffmpeg.org/download.html and put the executables next to bmusic.py
4. run `bmusic dQw4w9WgXcQ`
